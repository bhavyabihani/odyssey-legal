# Odyssey Privacy Policy

**Effective Date:** October 5, 2026  
**Last Updated:** October 5, 2026

This Privacy Policy explains how Odyssey ("Odyssey", "we", "us", or "our") collects, uses, stores, and processes information when you use the Odyssey Discord application ("Bot").

By adding or using Odyssey in a Discord server, you acknowledge the practices described in this Privacy Policy.

## 1. Information We Process

Depending on the features enabled by a server administrator, Odyssey may process:

- Discord user IDs
- Discord server IDs
- Discord channel IDs
- Discord role IDs
- Discord message IDs
- Usernames and display names
- Server, channel, and role names
- Discord permissions relevant to Odyssey's operation
- Server configuration information
- Message content when required for enabled features

Odyssey does not require your Discord password, authentication credentials, or Discord account token.

## 2. Messages and Content

Odyssey may process message content when required for features such as:

- AI chat
- AI AutoMod
- Normal AutoMod
- Custom commands
- Counting
- Leveling
- Chat-related automation
- Other features explicitly enabled by a server administrator

Message content is processed only as reasonably necessary to provide the relevant functionality.

## 3. Server Configuration

Odyssey may store configuration required to operate enabled features, including:

- Moderation settings
- AutoMod settings
- AI settings
- Welcome and leave settings
- Ticket settings
- Giveaway settings
- Leveling settings
- Reaction roles
- Custom commands
- Sticky messages
- Verification settings
- Logging settings
- Premium status
- Other server-specific configuration

## 4. Feature Data

Odyssey may store information required for features such as:

- Giveaway entries and winners
- Warning and moderation records
- Level and experience information
- Custom command configurations
- Ticket configurations
- Reaction-role configurations
- Server Premium status
- Other data necessary to provide enabled features

## 5. How We Use Information

We use processed information to:

- Operate Odyssey's features
- Respond to commands and interactions
- Provide moderation and security features
- Maintain server configurations
- Provide AI functionality when enabled
- Maintain giveaways, leveling, tickets, and other requested features
- Prevent abuse and maintain service reliability
- Diagnose technical problems
- Comply with applicable legal requirements

We do not sell Discord user data.

## 6. AI Processing

When AI features are enabled, relevant message content and conversation context may be processed by third-party AI service providers used by Odyssey.

Depending on availability and configuration, these services may include Google Gemini, Groq, or OpenRouter.

AI processing is used to provide features such as AI chat and AI AutoMod.

Users and server administrators should avoid submitting sensitive or confidential information to AI features.

## 7. Third-Party Services

Odyssey may use third-party infrastructure providers, database providers, hosting providers, and AI providers to operate its services.

Information may be transmitted to these providers when necessary to provide the requested functionality.

Odyssey does not sell personal information.

## 8. Data Retention

Information is retained only for as long as reasonably necessary to provide the relevant functionality, maintain server configuration, maintain security, resolve disputes, or comply with legal obligations.

When information is no longer necessary, it may be deleted or anonymized where reasonably practicable.

## 9. Data Deletion

A server administrator may remove Odyssey from a server at any time.

For requests concerning deletion of data associated with a Discord user or server, contact:

**dcbot.odyssey@gmail.com**

Please provide enough information for us to identify the relevant Discord server or data. Do not send passwords, authentication tokens, or other credentials.

Valid deletion requests will be handled in accordance with applicable law and Discord's requirements.

## 10. Server Administrator Responsibility

Server administrators control which Odyssey features are enabled in their servers.

Administrators are responsible for configuring Odyssey appropriately and ensuring they have the necessary authority to process information through the Bot.

## 11. Children's Privacy

Odyssey is a Discord application and does not knowingly seek to collect information from children below the minimum age permitted to use Discord or applicable law.

If you believe Odyssey has received information it should not have received, contact:

**dcbot.odyssey@gmail.com**

## 12. Security

We use reasonable measures designed to protect information processed by Odyssey.

However, no online service can guarantee absolute security.

Never share Discord bot tokens, API keys, passwords, or other authentication credentials publicly.

## 13. Changes

We may update this Privacy Policy when Odyssey's functionality, data practices, or applicable requirements change.

The updated version will include a new "Last Updated" date.
